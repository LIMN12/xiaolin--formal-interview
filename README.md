# 校园活动台 CampusHub

> 面向大学生的校园活动与机会信息分类平台 · 信息初步分类与质量初步评估
> 时间背景：2026-09-19　·　数据来源：考核题目提供的 26 条模拟校园信息

## 一、产品名称

**校园活动台 CampusHub** —— 把来源不同、质量不一的校园活动与机会信息，整理成同学能快速「发现、理解、参与」的结构化列表，并对广告/可疑内容给出明确提示。

## 二、解决的问题

大学生日常接触的信息来源复杂：学院/学校官方活动、学生自发约球/组队、以及夹杂其中的兼职推广、商品广告。问题集中在三点：

1. **来源混杂**：官方活动与学生自发信息混在一起，难以快速区分可信度。
2. **质量不一**：部分信息缺少时间、地点、费用、报名截止等关键字段；个别内容实际是推广广告，与校园活动关联弱。
3. **判断成本高**：新生尤其难以一眼判断某条信息是否完整、是否值得参与、是否需要警惕。

CampusHub 把这些信息按来源、类型、质量、时效四个维度分类展示，并主动标注缺失项和风险项，降低同学的判断成本。

## 三、主要功能

### 核心功能

1. **信息分类展示（任务1）**
   - 来源分类：学院/官方、学生自发、我发布的（带颜色徽章一眼区分）。
   - 类型分类：训练营、讲座/分享、团队招募、志愿服务、学习小组、竞赛、工作坊、约活动/交流、学习资料、补充通知、观摩、推广/广告。
   - 卡片式简洁明朗布局，每张卡含来源/类型/质量/状态四个徽章 + 时间/报名/地点/对象四项要点。

2. **学生自主发布 + 发起组队（任务2）**
   - 「发布活动」表单：学生可发布一般校园活动（讲座/约球/学习小组等），带类型分类标签，存 `localStorage` 并进入主列表。
   - 「发起组队」（核心）：生成一条**新的组队事务**进入主列表，带"组队"标记，别人看到后可点"申请加入"。这是创建新事务，不是从已有信息筛选。
   - 偏好条：发起组队时用滑块设置"队伍人数（1-8）""每周投入小时（1-20）"，用标签设置"需招募角色/技能方向/时间段/基础要求"；这些偏好作为该组队帖的招募条件在卡片上可视化展示（进度条 + 标签）。
   - 申请加入：组队帖带"申请加入"按钮，点击后标记"已申请"并提示联系发起人；状态存 `localStorage`，刷新仍在。
   - 轻量风控：联系方式含"私人微信/购买链接/兼职日结"等会被拦截并提示改用公开渠道。

3. **信息质量评测 + 广告治理（任务3）**
   - 三级质量标注：信息完整 / 部分缺失 / 风险提示（卡片层即一眼可见）。
   - 详情弹层内置「五维质量评估卡」：完整度、可信度、关联度、时效性、价值度，每维 0-5 分 + 进度条 + 文字讲解 + 总分。
   - 好信息：绿色评估卡，给出综合说明（来源可靠、信息较完整、可放心参与）。
   - 差信息/广告：红色风险卡 + "提示与警告"清单，逐条列出风险点（如要求私下联系、含购买链接、关联校园弱、时效缺失）。
   - **广告治理**：①关键词自动降级——发布时命中"私人微信/购买链接/兼职日结/刷单"等关键词，系统自动降级为广告类并标红警示；②折叠展示——广告/风险/被举报≥2 次的信息默认折叠为一条警示横幅，点击可展开；③用户举报——每条非自己发布的信息可点"!"举报，累计达 2 次触发折叠。

4. **多维筛选与搜索**
   - 来源标签切换（全部/官方/学生/我发布的，带数量计数）。
   - 类型下拉、质量下拉、关键词搜索（防抖）、一键重置。

5. **详情查看与收藏**
   - 点击卡片「≡」查看详情（含五维评估卡 + 原始信息回显，方便核对）。
   - 收藏功能，状态通过 `localStorage` 保留，刷新后仍在。

### 自主设计的实用/创新内容

1. **五维质量评估引擎**：不只分「官方/学生」，而是对每条信息做完整度/可信度/关联度/时效性/价值度五维打分，每维有进度条与文字讲解，把"质量评测"从模糊标签变成可量化、可讲解的评估卡。好信息给绿色说明、差信息给红色风险清单，对应题目「对不同质量信息做出评测提醒」。

2. **发起组队 + 偏好条（创建新事务）**：任务2 不做"从已有信息筛选匹配"，而是让学生**生成一条新的组队事务**进入主列表，并通过偏好条（滑块控人数/投入、标签控角色/技能/时间/基础）把"我想找什么样的队友"具象化展示在帖子上；别人看到偏好后可直接"申请加入"，把组队从"被动找信息"变成"主动建队+被申请"。

3. **广告治理三件套**：①关键词自动降级（发布命中推广词即降级为广告类+警示）；②风险折叠（广告/被举报≥2 次默认折叠为警示横幅，点击展开）；③用户举报（每条信息可举报，累计达阈值触发折叠）。既不直接删除（保留判断权），又降低广告对正常信息的干扰。

4. **补充通知关联机制**：题目中 09 是 01 训练营的场地/时间补充通知、20 是 03 招募的名额补充说明。CampusHub 在卡片上标注「关联编号」，并在详情中展示，避免同学只看到旧通知而错过更新。

5. **时效状态自动标注**：以考核当日 2026-09-19 为基准，自动把信息标为「今日进行 / 即将开始 / 报名中 / 长期招募 / 可候补 / 已结束回放待出 / 补充更新 / 风险提示」，让同学优先看到当下该关注的内容（如 02、10、18 三场今日活动会被高亮）。

6. **「题目未提供即不编造」原则**：所有缺失信息以「部分缺失」+ 提示形式呈现，绝不擅自补全费用、地点等题目没有的事实；评估扣分也只针对真实缺失项。

## 四、运行或使用说明

### 环境要求

- 任意现代浏览器（Chrome / Edge / Firefox / Safari）。
- 纯前端项目，**无需安装任何依赖、无需后端、无需数据库、无需构建**。

### 运行方式

1. 克隆仓库：
   ```bash
   git clone https://github.com/LIMN12/xiaolin--formal-interview.git
   ```
2. 进入项目目录：
   ```bash
   cd xiaolin--formal-interview/campus-hub
   ```
3. 双击 `index.html` 用浏览器打开即可运行。

> 也可用任意静态服务器（如 `npx serve` 或 VS Code Live Server）打开 `campus-hub/index.html`，效果一致。

### 使用流程

1. 打开页面后看到 26 条信息的分类卡片与统计条。
2. 用顶部「全部 / 学院官方 / 学生自发 / 我发布的」标签切换来源。
3. 用「类型」「质量」下拉进一步筛选，或在搜索框输入关键词（如「训练营」「AI」「兼职」）。
4. 点击卡片右下「≡」查看详情（含五维质量评估卡）；点击「☆」收藏（刷新后仍在）。
5. **发起组队**：点右上「发起组队」，填标题/方向，用偏好条滑块设队伍人数与每周投入，用标签选角色/技能/时间/基础，提交后生成新组队帖进入主列表，别人可点「申请加入」。
6. **广告治理**：广告/风险信息默认折叠为警示横幅（点击展开）；点卡片右下「!」可举报，累计 2 次触发折叠；发布时命中推广关键词会被自动降级。

## 八、展示页 showcase（任务4 · 页面优化 v3）

> 版本：第三版；页面优化。在 campus-hub 功能应用之外，新增 `showcase/` 两个纯展示页，调取本仓库 GitHub 数据，复古胶片电影质感。

### 产品名称

**CampusHub Showcase** —— 基于本仓库 GitHub 事项数据的复古电影质感展示页。

### 解决的问题

功能应用 campus-hub 解决「信息分类与质量评估」；展示页 showcase 解决「让仓库的开发轨迹被直观看见」：把 commits、文件、issues、releases 这些 GitHub 事项，以电影海报式的复古视觉呈现，既能当作品集展示页，也让评审一眼看清仓库的演进脉络。

### 主要功能

1. **页面1 · 贡献日历图**（`showcase/index.html`）：按 GitHub 贡献热力图思路，把 2026 年全年 12 个月排成日历网格，按当天 commit 数量分四级配色（做旧米 → 芥末金 → 橙 → 铁锈红），仓库的 commit 日期高亮；下方倒序时间线展示每条 commit 的标题、作者、SHA、时间。
2. **页面2 · 积分榜**（`showcase/standings.html`）：参考赛事积分榜排版，深色 Hero + 巨型 `STANDINGS` 标题 + 仓库统计浮卡；主体为 `Commits / Files` 双 Tab 表格，最新 commit 行用橄榄绿高亮贯穿；底部浅色图库横向滚动卡片阵列 + 箭头导航。
3. **数据调取**：`showcase.js` 实时 `fetch` GitHub REST API（commits/contents/issues/pulls/releases + 仓库元信息）；`file://` 直开或网络受限时自动回退 2026-09-19 同步的本地快照，双击即开不报错。

### 运行或使用说明

1. 双击 `showcase/index.html` 用浏览器打开（走本地快照数据，无需联网）。
2. 如需实时调取 GitHub 数据：用 VS Code Live Server 打开 `showcase/` 目录，访问 `index.html` / `standings.html`。
3. 两页之间通过底部链接互相跳转。

### 自主设计的实用或创新内容

1. **复古胶片电影质感系统**：配色取自参考图3 的复古印刷色（铁锈红 / 芥末金 / 做旧米 / 深棕黑 + 藏蓝/橄榄绿/橙层次），叠加 SVG 颗粒噪点动画层 + 径向暗角 + 套色偏移文字（青/红错位模拟印刷对版不准），全站色调统一。
2. **字体三重奏**：Oswald（压缩无衬线巨型标题）+ Playfair Display（衬线电影海报）+ Special Elite（打字机复古标注），不沿用 campus-hub 的字体。
3. **纯矢量复古插画**：星形、太阳轮、条纹色块、小号手剪影等插图全部 SVG 手绘，不引入位图，零图片依赖。
4. **GitHub 事项 → 日历热力**：把仓库 commits 按日期聚合成贡献日历，让"3 个 commit 都在 09-19"这一事实一眼可见，比 commit 列表更直观。
5. **实时调取 + 快照兜底**：纯前端、零依赖、零构建，但仍能真正调取 GitHub 数据；离线降级到快照，保证展示页任何时候都能打开。
